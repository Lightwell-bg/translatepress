# Быстрый старт

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Lightwell-bg/translatepress.git translatepress
   cd translatepress
   ```

2. Установите зависимости для тестов (нужны PHP 8.1+ и Composer):

   ```bash
   composer install
   ```

3. Запустите тесты:

   ```bash
   php vendor/bin/phpunit
   ```

4. Соберите установочный ZIP:

   ```bash
   php bin/build-zip.php
   ```

   Архив появится в `dist/_<N>wp-mlp.zip` (папка внутри архива — `wp-mlp/`); путь и версия печатаются в конце вывода.

5. В админке WordPress: «Плагины → Добавить новый → Загрузить плагин», выберите ZIP из `dist/` и нажмите «Установить».

6. Нажмите «Активировать плагин».

7. Откройте «Настройки → Постоянные ссылки» и нажмите «Сохранить изменения» (структура — любая, кроме «Простые»).

8. Откройте «Мультиязычность → Языки». В блоке «Ключ OpenAI» вставьте ключ из https://platform.openai.com/api-keys, нажмите «Сохранить», затем в поле «Модель OpenAI» выберите модель из списка (список появляется после сохранения ключа; по умолчанию модель не выбрана, а без неё кнопка «Перевести с ИИ» не появится даже при сохранённом ключе; свою можно вписать через «Другая модель…») и снова нажмите «Сохранить». Шаг нужен только для кнопки «Перевести с ИИ».

9. Откройте в браузере `https://ваш-сайт/en/` — должна открыться английская версия сайта.

10. Для перевода страницы откройте «Мультиязычность → Визуальный редактор».

11. Чтобы на других языках были видны только проверенные записи: «Мультиязычность → Языки → Непереведённые записи» → «Показывать на языке только записи, включённые вручную», нажмите «Включить все полностью переведённые на …» и «Сохранить»; дальше включайте записи выключателем «на сайте» в колонке «Языки» списка записей.
